## 架构与质量要求贯穿每轮

- Core 只依赖自有领域类型和接口，模型、工具、存储、宿主各有明确责任。先稳定最小契约和符合性测试，再扩展；不在本计划强行固定未评审的 API 字段、框架或包目录。
