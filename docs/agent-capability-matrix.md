# Agent 实际使用能力与验收矩阵

状态：规划补充；版本 r4；2026-11-18。同步[路线图 r7](iteration-plan.md)与 [npm 发布方案](npm-release-plan.md)。当前只验收 TUI 范围，SP010 继续验证通用宿主接口。

## 复查结论与比较范围

原计划覆盖编码闭环，但对终端体验、Git 隔离、指令冲突、追问、任务拆解、真实开发环境和高级能力缺少明确出口。补齐这些能力后，修订后的 16 个 SP 构成当前交付路线，但不能靠计划证明达到原 Agent 效果，也不能保证每轮同样长度或无需拆轮。

本轮只核对新仓规划，并以旧仓 README 的公开功能描述作能力盘点参考；未复制旧源码，未运行原 Agent，也没有审计其全部命令和实际效果。参考描述包含多项目/会话、worktree、diff、审批、模型、Computer Use、远程访问、IM、调度和用量；它们是能力线索，不是已测量基线。原文不迁入新仓。SP001 已固定能力清单、真实任务与测量条件；用户决议 O5=B（2026-11-16）不采集原产品效果基线，不再以原产品为对照运行，效果口径为自有测量 + 能力清单覆盖度。

多代理团队、浏览器、Computer Use 和定时任务仍是必交。Desktop、VS Code、远程/H5 与 IM 移出当前交付及验收。功能拆分见[高级能力计划](advanced-capabilities-plan.md)。SP012 做中期检查，SP021 给出当前范围的完整替代结论。
项目没有需求 ID。表格按功能名称索引，正式材料保存在对应 SP 的功能/优化目录；验收条件可在功能内使用 AC-01 等编号。

SP001 已把本矩阵的能力条目落成可勾选的[能力清单 v1.2](../SP/SP001/capability-baseline/capability-manifest.md)（85 项，必交 47 项、范围外 7 项，覆盖度分母固定为 47；v1 分母 53 经用户 2026-11-17 决定调整）。本矩阵是**验收视角**，能力清单是**能力视角**，两者互补而非重复；清单是后续各轮出口门槛的对照依据。

2026-11-17 起剩余 SP 以[参考复刻排查](reference-tui-replication-audit.md)为对照补充：逐轮参考事实/补充任务、缺口（manifest v2 提议）与独立实现周旋点在该文件维护；本矩阵的最低出口不变，排查只增补行为对照清单，不降低任何门槛。

统一数据边界为当前用户 home 下的 `~/.budingx`；验收需在两个不同临时 home 下证明隔离、路径不硬编码，也不读取 `~/.claude`。bootstrap 暂无文件持久化，不能将目录约定当作数据存储已实现。

## 每轮不可跳过的负向场景

- Provider/MCP/网络不可用时返回可诊断状态，不假装任务完成；取消从 UI/CLI 到模型、工具、子代理和后台命令传播。
- 遇到 repo 指令、网页、工具输出或模型请求中的越权内容，不提升权限、不泄露凭据；本地进程权限限制不能被宣称为完整 OS 沙箱。
- 写入/会话迁移/共享失败必须保留原数据；权限拒绝与外部改动不造成破坏；恢复时对不确定的执行结果先核对。
- TUI 安装后独立完成核心编码任务；用户无需手动运行服务，宿主崩溃有明确错误和恢复；Node 前置要求与支持平台如实声明。未来恢复各端按 SP010 入口契约独立验收，不依赖 TUI 进程常驻。

## “达到效果”的最终判定

先逐项给出已实现/未实现/未测量，再评估任务效果。SP021 至少提交：任务及快照版本、固定环境/模型/预算、自有任务逐次结果、总体与关键分组结果、置信区间或波动说明、失败归因、性能/成本、TUI 场景和用户试用证据（用户决议 O5=B：不对照原产品，无「双方结果」要求）。安全负向用例必须全部通过；模型差异和样本量限制必须可见。

原路线图的 5 个百分点非劣门槛已被用户决议 O5=B（2026-11-16）废除：不采集原产品基线，效果判定采用自有测量与能力清单覆盖度。30 题×3 次是起点，不自动证明统计显著或全量覆盖。结果区间跨越后续轮次固定的适用门槛时记“证据不足”，增加独立任务/运行，不宣称对齐。盲测题在封版前不能用于反复调优；失败分析后进入下一版本回归，同时保留新的独立盲测。

任何当前必交项 FAIL/UNVERIFIED 都阻止完整替代结论；不能以候选/延期措辞绕过用户已确认的范围，改变验收范围须用户明确决定。最终任务集扩充为至少 30 个基本编码 + 30 个高级组合任务、至少 20 个独立盲测，分组门槛见路线图 r3；REM/IM 题目仅保留作历史，SP020 开轮前以 inventory v2 补齐当前范围配额。
