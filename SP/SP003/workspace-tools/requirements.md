# 工作区文件工具 · workspace-tools

状态：DRAFT｜版本：v0.1｜迭代：SP003｜来源身份：USER_CONFIRMED（路线图功能名与出口门槛 + 2026-11-17 三权限模式决定）+ MODEL_PROPOSED（AC 切分与工具契约）

## 来源与目标

- 路线图 SP003（USER_CONFIRMED）：功能目录 workspace-tools；出口「跨目录搜索、编码/CRLF/大文件/忽略规则、补丁冲突、目录穿越/junction 越界有回归」。
- 能力矩阵（USER_CONFIRMED 范围）：CAP-L2-01 文件读取（受工作区边界约束的读取）、CAP-L2-03 搜索与匹配（glob/grep，可复现、可截断、遵守忽略规则）、CAP-L2-07 路径越界防护（越界写入被拒绝且磁盘不变）、CAP-L2-02 文件编辑（原子写 + 预览 + 可撤销，可撤销部分落在 change-preview）。
- 排查文档 SP003 条目（参考事实，仅行为对照）：@/命令统一 typeahead；Glob/Grep 截断与计数摘要；Edit 唯一字面串/replace_all/空串创建/old==new 拒绝/容错回退；Read 行范围与图片尺寸摘要。
- 当前仓库事实（2026-11-17，`master` = `b0ffc9e`）：`src/core` 只有会话/事件/工具端口契约，`src/storage` 只负责用户数据根（`~/.budingx`）的配置与凭据，**没有任何文件工具实现**，`Session` 通过 `ToolHandler` 端口预留了工具接入点但运行时尚未注册任何工具。
- 本轮目标：交付一组可被模型调用、受工作区边界与权限模式约束的文件工具，行为可复现、结果可截断、错误可读。

## 范围与非目标

**范围**：工作区根的确定与路径解析（含符号链接/junction 真实路径校验）；读取（行范围、截断、编码/二进制/CRLF/大文件策略）；写入（原子写、创建/覆盖、并发基线校验）；精确编辑（唯一字面串、replace_all、空串创建、old==new 拒绝、匹配数不符拒绝）；glob 模式匹配；grep 正则匹配；忽略规则（.gitignore/.ignore 语义、目录级规则）；跨目录递归搜索；工具结果与错误给模型的统一形态；工具参数 schema 与取消传播。
**非目标**：命令执行与 shell 沙箱（SP004）；diff 预览与撤销（change-preview，本轮只提供写盘前的基线校验与结果回执）；权限判定与审批交互（permission-controls，本轮只提供「是否需要审批」所需的能力分类）；@ 补全与文件上下文注入（file-context，本轮只暴露可被其复用的路径解析与读取能力）；二进制文件的多模态传递（SP007）；Git 感知与 worktree（SP004）；大仓索引与语义检索（SP007 可选）。

## 验收条件

| AC ID | 前置条件 / 输入 | 操作 | 可观察结果 | 验证方式 |
| --- | --- | --- | --- | --- |
| WT-01 | 工作区内 UTF-8 文本文件，含多行 | Read（不带范围） | 返回带行号的内容，行号格式与总行数可读；尾部附截断提示（若被截断） | 单测（真实临时文件） |
| WT-02 | 文本文件行数 ≥ 上下限 | Read 带 `offset`/`limit` | 只返回请求区间；越界区间返回明确错误而非空串；区间端点语义有文档 | 单测 |
| WT-03 | UTF-16 / 非法字节序列文件；>10MB 文件；CRLF 文件 | Read 各一次 | 每类有明确策略与可读提示（UTF-16 与非法字节明确拒绝并说明；大文件按上限截断并标注；CRLF 统一为 LF 呈现且不改磁盘） | 单测 |
| WT-04 | 目标不存在 / 目标为目录 / 父目录不存在 | Write 各一次 | 分别返回不同可读错误；失败时磁盘不变（无残留临时文件） | 单测 + 真实进程 |
| WT-05 | 已存在文件 | Write | 内容以原子方式落盘（临时文件 + rename）；写后读回内容一致；原文件权限属性不被意外改写 | 单测 + 真实进程 |
| WT-06 | 目标文件在写入前被外部改动 | Write / Edit | 基线指纹不一致时拒绝写入并说明冲突，磁盘保留外部改动，不做覆盖 | 单测（模拟外部改动） |
| WT-07 | 文本中 `old_string` 唯一出现 / 出现多次 / 不存在 / 与 `new_string` 相同 | Edit 各一次 | 唯一命中才替换；多处命中要求显式 `replace_all` 或指明次数，否则拒绝；不存在时拒绝并提示最接近片段；old==new 拒绝 | 单测 |
| WT-08 | Edit `old_string` 为空字符串 | Edit | 按「创建文件」语义处理（仅当目标不存在）；目标已存在时拒绝 | 单测 |
| WT-09 | 目录树，含忽略文件与嵌套子目录 | Glob 模式匹配 | 递归匹配；遵守忽略规则；结果按稳定顺序排列；超出上限时截断并输出计数摘要（总数/已显示数） | 单测（真实临时目录） |
| WT-10 | 多文件目录树，含二进制文件与忽略文件 | Grep 正则 | 递归匹配输出 `文件:行号:内容`；二进制文件跳过并计数；遵守忽略规则；结果超出上限时截断并输出计数摘要 | 单测 |
| WT-11 | 相对路径 `../` 越界、绝对路径指向工作区外、指向 junction/symlink 指向区外的路径 | Read / Write / Edit / Glob / Grep 各一次 | 全部拒绝，错误说明越界原因；工作区外文件内容不被读出、磁盘不被修改 | 单测（真实 junction/symlink，Windows 上 junction 可创建） |
| WT-12 | 包含 `.gitignore`（根与子目录）、`.ignore` 的目录树 | 读取/搜索各一次 | 忽略规则按语义生效（可取反 `!`、目录级规则、锚定 `/`）；被忽略文件不出现在结果中；忽略本身失败不导致整体失败 | 单测 |
| WT-13 | 任一工具执行中 | 用户中断当前回合 | 工具执行收到 AbortSignal 后尽快停止；已产生的部分写盘不残留中间状态 | 单测 |
| WT-14 | 任一工具失败（文件不存在、权限不足、编码不支持等） | 调用 | 错误以统一形态回给模型（可读消息 + 稳定错误码），会话不中断，模型可继续下一动作 | 单测 |

## 依赖、风险与开放问题

- 依赖：SP002 的 `ToolHandler` 端口（`src/core/tools.ts`）、`ToolContext`（含 AbortSignal）、会话事件契约（`src/core/events.ts`）；本轮新增 workspace 模块与 storage 的路径解析复用。权限判定接口由 permission-controls 提供（依赖方向：workspace → 权限端口，不反向）。
- 许可与来源：全部实现独立编写（`node:fs`/`node:path`/`node:crypto` 等 Node 内置能力）；gitignore 语义与 diff 算法按公开规范自实现，不引入第三方库，不迁入参考仓源码。参考仓仅作行为对照。
- 风险：gitignore 语义自实现易有偏差 → 以公开规范 + 覆盖用例固定；大目录递归搜索性能与内存 → 设定默认上限与摘要；Windows 路径大小写与长路径 → 真实路径比较与显式长路径处理。
- OPEN：默认截断上限与行号格式的具体取值在设计阶段定为可配置常量并记入设计；图片读取返回摘要（本轮只返回尺寸/类型摘要，不做多模态传输，SP007 处理）。
