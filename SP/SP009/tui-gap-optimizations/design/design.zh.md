## 2. #42 工具输出和子代理失败（AC-SUBAGENT-01…03）

- WebFetch 的下载字节、重定向、权限及时间预算保持现行配置。工具返回的头、正文及提示共用 Core 的 32768 UTF-16 码元上限，裁剪点避免拆开 Unicode 代理对。结果写明上限与是否截断，截断提示引导换更窄的 URL、章节或其他来源。下载和读取响应体使用同一超时信号，保留取消，并区分网络、HTTP 状态、私网、超时。直接调用抓取函数保留其下载结果契约。
- Core 在任意工具成功但输出超长时附截断标记，保持成功结果，不积累失败次数。真正失败即使错误正文超长也保留原错误码和熔断计数。原有同参数熔断与换参数同错误码熔断阈值保留，前者建议停止相同重试，后者建议更换工具或获取策略。父 Agent 工具的失败计数不放宽。
- 子代理运行时从实际工具结果收集最近三个成功工具、最近三个失败工具以及最多 800 码元的参数和结果摘要。宿主用已有脱敏器处理新诊断字段。真实执行错误触发熔断时正常返回结构化 `AGENT_FAILED`，由父回合继续决策。父模型收到子代理 ID、终止码、失败工具、参数摘要、工具错误码、部分输出以及建议。成功、取消、预算、并行及审批结果沿用现有合同。后台通知沿用系统消息展示，模型通知和 `TaskOutput` 包含失败原因。父代理根据说明决定是否换策略，调度器不自动重发。
- 验证先走真实 HTTP fixture 和生产工具调用链，再跑允许访问的公开长页面。最终真实 Provider 至少三次，要求可追踪 Agent → WebFetch → 子代理结论，且无 `AGENT_FAILED`。用隔离授权的 Provider 配置，记录用量、错误码和脱敏证据。

## 3. 会话与导出（AC-FORK-01…02、AC-NAME-01…02、AC-RESUME-01…02、AC-EXPORT-01…02）

- `/branch [session-id]`（`/fork` 别名）选择当前或当前工作区中已保存的会话。当前会话静止后先 flush，历史源取完整转录快照。派生分支以 UUID 独立保存，以派生时的最后消息为分支点，继承权限且仍在当前策略下重新应用，保留待核对工具步骤；不复制 writer lock、工作树绑定、后台任务或凭据。先在不可恢复的临时路径内生成数据，完整落盘后原子发布；成功后将当前入口切换到新 ID。失败保持源会话可用。可并发取同源，一次派生占一个独立 ID。
- `/rename <标题>` 编辑当前会话标题，写入独立用户标题元数据字段，兼容旧自动标题，空、换行控制字符或超过 80 个 Unicode 字符时拒绝。并发以已持有的会话写锁串行化，读取其余元数据后累加更新。命令保留 ID、转录和导出引用。
- `/resume` 内输入搜索词，标题和持久化正文用 Unicode 标准化的子串匹配。每次打开选择器生成当前工作区至多 200 个最近会话的内存索引。每份正文索引至多 256 KiB 有效 UTF-8 文本，优先最近记录；索引关闭即释放，下一次打开重读。不读技能指令、思考、工具参数或内部提示；无法读取的会话从搜索中剔除。上下键、Enter、Backspace 和 Esc 沿用选择器习惯，空查询显示可恢复列表。
- `/export --format markdown [--session <id>]` 和既有无头入口从统一序列化器输出 Markdown。修改证据仅来自已持久化、可归属到该会话的结构化文件工具写入记录及摘要。普通 Shell/Git 命令没有结构化写入记录时标为无证据，不用当前 Git diff 追溯历史。没有可归属记录的旧会话给出缺失说明。Markdown 保留正文中的围栏代码和中文，转义用于标题及路径的 Markdown 元字符。禁止带出凭据与隐藏技能指令。仅在通过现有 containment 检查的路径以独占写入方式发布。

## 4. 输入与转录（AC-INPUT-01…02、AC-TRANSCRIPT-01…02）

- 使用已有编辑缓冲。Ctrl+S 在当前会话内收起未发送草稿，保留文本、光标和粘贴引用，空编辑区可取回已有草稿。历史搜索 Esc 恢复当时的编辑内容，草稿槽和历史分开。会话切换清空草稿槽和未确认粘贴，提交独立新文字后可重新取回。取回永不发送。
- 单次粘贴超过 10000 UTF-16 码元时折叠显示。查看操作能展开，发送该草稿第一次提交确认、第二次提交执行，后续编辑撤销确认。输入累计上限 100000 UTF-16 码元，插入使总量超限时整次拒绝并保留原输入，普通输入、撤销及图片处理保持现行语义。确认时发完整已保留的纯文本。
- 转录沿用 Ctrl+O。Ctrl+E 在转录视图切换全量展开，在常规视图保持命令/待办卡片。转录上下键选择思考段，Enter 逐条展开或收起，默认只显示摘要。思考内容使用已收到且允许展示的事件或持久化思考字段，缺失内容显示缺失，内部签名和协议字段不展示。工具卡片依调用 ID 更新，合并相邻同类成功摘要，通知继续由系统消息呈现，审批在窄屏下可操作。离开后本会话保留滚动和选择，恢复旧记录按可见消息锚点定位。

## 5. 规则与技能（AC-RULES-01…02、AC-SKILL-01…03）

- 复用 Markdown token 位置识别叶节点里的协议 `@path`、`@./path`、`@~/path` 和绝对路径。仓库导入只在规范化且 realpath 校验后的可信根，用户规则只在授权配置根及同样受信的当前工作区。文件和目录规范路径去重，导入深度最多 5，沿用 64 KiB/128 KiB 预算。报告源位置、原因和错误类，忽略代码、无效和越界引用。每回合刷新。规则按当前活动目录生效。局部作用域以工具结构化声明的路径或 cwd 为准。多目标有不同作用域时分别报告规则，并要求拆分调用。命令字符串内的 `cd` 不改变声明的工具 cwd 或局部规则作用域。工具触及新的作用域时先交回所需规则，让模型重新提交操作，再进入现有权限和批准流程。兄弟目录规则不进入全局提示。压缩/恢复触发重新解析。
- 保留用户、近到远项目、内置的技能优先级。两个禁用开关分别影响用户命令及模型目录。复用同一加载/资源解析，`/reload-skills` 刷新定义但不会改变本回合已激活技能的权限契约。相对资源显式从技能根解析，路径越界、符号链接越界、循环或超限报出资源位置。隐藏提示继续内部注入。
- 技能 `allowed-tools` 是限制集合。Core 在本回合内把已激活限制与现有审批和权限裁决相交，多技能取交集；拒绝时不执行。未声明对应字段按原会话策略。结束、取消、压缩后下一回合的权限重新解析，限制不跨回合泄漏。模型调用通过现有工具装配加入 `Skill` 能力，手动命令用于本回合注入同一技能。两条调用路径都接受禁止开关和资源检查。

## 6. 任务与 Worktree（AC-TASKS-01…02、AC-WORKTREE-01…03）

- `/tasks` 按类型显示当前会话任务。上下键/Enter 进入详情，详情可读该任务的已授权输出尾部（最多 32 KiB），路径由登记表解析并核对归属，显示退出码、失败或无日志原因。列表或详情按 `s` 后确认停止，路由到现有 Shell 与 Agent 停止能力。重启后没有活动任务的所有权，不接管旧进程，退出竞态以当前终态为准。
- `/worktree enter <slug>`、`exit`、`merge <slug>` 补齐现有命令。单一运行时工作目录同时用于 workspace 工具、Shell、Git、引用、审批与局部规则。切换须保证会话空闲且当前工作目录无仍运行的任务，准备新运行时后持久化会话元信息，再切换。撤销、失败与失效恢复使用已验证的原目录或要求修复绑定，禁止把原本指向失效工作树的操作静默投递到其他目录。项目身份保持为来源工作区，会话活动目录独立记录。
- 合并目标固定为来源工作区当前绑定的分支。当前分支已变化时，拒绝并要求改回绑定目标。命令只做 Git 快进或普通合并，源和目标都必须干净且无进行中 Git 操作，审批中显示两侧分支与提交；审批后复核 HEAD、工作区与暂存区。发生冲突时保留 Git 原生冲突状态以供解决，不执行 reset、stash、自动清理或推送。删除仍只受本次独立批准，未合并或不干净默认拒绝。会话绑定、审批与任务检查不绕开三档权限。

## 7. MCP（AC-MCP-01…03）

- 一套连接管理服务，保留原 stdio 配置和入口。远程增加 Streamable HTTP、旧 SSE 与 WebSocket 传输，使用已有 JSON-RPC 消息和超时。TUI、headless、serve owner 使用同一管理器；observer 不启动扩展。远程断开触发有界指数退避最多 5 次，只重新建立连接和目录，不重放待完成调用；手动停用停止重连。其他服务器及工具不因单连接错误持续冻结。工具和资源按已连接来源即时更新，资源 list/read 走同一权限和来源校验。
- `/mcp` 补服务器启、停、重连操作，状态表只显示协议与脱敏地址。远程认证使用独立 secret 引用或显式传给进程的环境变量，认证信息不转发给另一来源，不输出日志。当前版本不声明 OAuth 和 sampling。仅支持可呈现的 elicitation 请求；TUI 展示并确认，取消与超时结束请求，非交互按已有权限策略显式拒绝需要交互的请求。
