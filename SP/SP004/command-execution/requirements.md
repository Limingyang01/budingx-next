# command-execution · 命令执行

状态：ACTIVE（2026-11-18 开轮；v0.2 经参考仓审计修订）｜版本：v0.2｜来源：路线图 SP004（USER_CONFIRMED）+ 参考仓行为事实盘点与只读审计（只读参考）

## 目标

Agent 能在工作区内以受控方式执行真实进程命令：跨平台 shell（Windows 引号/路径/编码）、cwd 与环境可控、超时与非零退出码可诊断、输出有上限、后台任务可查可取消并**落盘可再读**、阻塞超预算**自动转后台**；命令执行与文件写入共享 SP003 的三档权限判定与底线规则。

## 边界

- 只做「执行命令」与「后台任务管理」；不做交互式 TTY（明确失败，不无限挂起）。
- 不做子代理派发（SP007）、浏览器/CU（SP012/SP013）、远程（r7 已移出当前范围）、定时任务（SP014）。
- 不做 Git 写操作（提交/合并/推送）：属 `git-worktree-safety` 需求，且无授权不执行。
- **不做 OS 级沙箱**（r7 CAP-L3-09 已降为可选，目标状态为「明确声明能力与局限，不冒充 OS 沙箱」）：本轮交付**能力声明层**，OS 级隔离留 SP011 worktree-isolation。

## 验收条件（AC）

- **CE-01** Given 任意命令，When 通过 Bash 工具执行，Then 返回退出码、stdout、stderr 三部分且非零退出码不被吞掉。
- **CE-02** Given 含空格/中文/Unicode 的路径，When 作为 cwd 或参数传入，Then 在 Windows 与 POSIX 上均可正确传递，不发生引号截断。
- **CE-03** Given Windows，When 执行含 `& | > ^` 等元字符的命令，Then 引号规则确定且可复现（元字符不被意外解释）。
- **CE-04** Given 超过 timeout 的命令，When 到达上限，Then 进程被终止并返回超时状态，不悬挂。
- **CE-05** Given 超长输出，When 输出超过上限，Then 截断并显式标注被截断，不把无限输出灌进上下文。
- **CE-06** Given `run_in_background`，When 命令启动，Then 立即返回任务句柄，后续可查询状态与输出，并可取消。
- **CE-07** Given 后台任务，When 用户取消，Then 整棵进程树被终止，状态为 cancelled。
- **CE-08** Given 只读模式（仅可查看），When 执行会写文件的命令，Then 被拒绝，磁盘不变。
- **CE-09** Given 工作区内修改模式，When 执行命令，Then 按判定结果询问/允许/拒绝；拒绝时命令不执行。只读命令族按**结构化命令表**豁免，未知参数不豁免。
- **CE-10** Given 完全权限模式，When 执行命令，Then 自动执行，但仍不得绕过底线规则（越界路径、凭据文件、`~/.budingx`、`.git`）。
- **CE-11** Given 命令引用凭据类路径或 `~/.budingx`，When 判定，Then 一律拒绝且原因可读。
- **CE-12** Given 需要交互式输入的命令，When 执行，Then 明确失败并提示原因，不无限挂起。
- **CE-13** Given `sleep`/`ping` 等阻塞等待类命令，When 检测到，Then 拦截并引导改用后台方式。
- **CE-14** Given 命令执行期间用户中断，When 取消信号传播，Then 进程树终止且回合进入取消态。
- **CE-15** Given 环境变量与 cwd 显式传入，When 执行，Then 生效且不泄漏宿主无关环境到输出。
- **CE-16** Given 前台命令超过阻塞预算（15 秒），When 仍未结束，Then 自动转入后台并回传任务 ID 与输出文件路径，回合不因此阻塞。
- **CE-17** Given 后台任务，When 产生输出，Then 完整输出写入会话隔离目录下的任务文件，模型可在后续轮次按路径读取；超大输出同样落盘并回传原始字节数。
- **CE-18** Given 命令命中破坏性模式（`git reset --hard`、`git push --force`、`git clean -f`、`rm -rf` 等），When 审批，Then 弹窗显示不可逆后果警告；警告本身不自动拒绝（底线规则仍优先拒绝）。
- **CE-19** Given 完全权限模式，When 策略声明了禁止写/禁止读的路径与网络域名，Then 该声明仍然生效（完全权限不等于无限制）；且不提供「关闭沙箱」类绕过参数。
- **CE-20** Given 命令是受限形式的原地编辑（`sed -i 's/a/b/g' file`），When 执行，Then 只允许替换语义、拒绝其他 sed 命令与危险参数组合、校验目标路径在工作区内，并以结构化 diff 呈现改动。
