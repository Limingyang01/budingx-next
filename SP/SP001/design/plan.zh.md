## 复审重点（Review Focus）

规格隐含、但任何单条任务的检查都不覆盖的五类失败模式：

1. **必交能力被静默降级**——清单里某项 `必交` 被改成 `建议`/`可选`，下游按固定分母 53 验收时会漏判，且无任何测试会失败。
2. **未证基线被写成结论**——文档出现被禁用的「已对齐原 Agent」「达到同等水平（效果）」这类达成声明，而原产品从未被运行过。
3. **Core 依赖终端/UI 库**——`src/core/` 引入终端渲染库，破坏 I-01，Desktop/VS Code 端无法复用 Core。
4. **触碰 `~/.claude` 或硬编码用户路径**——出现 `~/.claude` 的读写回退，或把用户名/盘符写进文档与代码。
5. **包名冲突未决即发布**——在 OPEN-01 未决前按 `budingx` 同名发布，覆盖用户已安装的 0.1.1 预览版。

上述五项在 T-001、T-002、T-003、T-008 各有对应核对步骤。
