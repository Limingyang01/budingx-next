# 模型配置管理 · model-management

状态：APPROVED（v0.1 用户 2026-11-16 会话「批准」）｜迭代：SP002｜来源身份：USER_CONFIRMED（通用 provider、不指定服务）+ 路线图（名称与出口）+ MODEL_PROPOSED（AC 切分）

## 来源与目标

- USER_CONFIRMED：路线图出口「真实模型配置…有证据」；能力矩阵「配置与模型管理」行：添加/编辑/删除/验证模型、切换默认和会话模型；错误 endpoint/凭据/不支持工具有明确反馈；会话使用固定配置快照，切换不误用旧凭据。
- USER_CONFIRMED（2026-11-16）：未指定服务 → 模型档案 = 名称 + base URL + key + 能力标记的通用结构。
- 不变量：数据根仅 `~/.budingx`（`os.homedir()` 解析），禁止读写 `~/.claude`（I 系列 + AGENTS）；凭据不入普通共享 JSON、不进日志（SP001 AC-09 边界）；持久化首次建立即版本化、原子写（路线图质量要求）。
- 现状缺陷（MODEL_PROPOSED 转述自源码盘点）：预览版仅环境变量/参数配置；`/model`、`/endpoint` 直接清空整个会话；endpoint 变更时粗暴删除 key——本轮修复体验但**保留「不把 key 转发给别的主机」的安全语义**。

## 范围与非目标

**范围**：模型档案 CRUD 与持久化（`~/.budingx` 下配置文件 + 凭据存储）；连通性验证动作；默认模型；会话内切换（回合边界生效，配合 session-lifecycle 快照）；能力标记（至少：是否支持工具调用）；校验规则沿用 `normalizeBaseUrl`/模型名/key 合法性检查；跨重启可读。
**非目标**：跨端共享模型库与并发写保护（SP008）；OAuth/订阅型登录流；多用户隔离；模型目录自动发现；加密静态存储（本轮按保守文件权限 + 不进日志，方案在设计定）。

## 验收条件

| AC ID | 输入 / 动作 | 可观察结果 | 验证方式 |
| --- | --- | --- | --- |
| MM-01 | 添加/编辑/删除/设默认；重启进程 | 全部持久化并正确加载；写入为原子（临时文件+rename），中断不留半写文件；配置文件带 schema 版本字段 | 单测（临时 HOME fixture） |
| MM-02 | 对某档案执行「验证」 | 成功或失败有明确分类（不可达/鉴权/模型不存在/协议不符/工具能力不符）；输出与日志无 key 明文 | 假 provider 单测；live 归 PS-08 |
| MM-03 | 会话中 `/model` 切换 | **会话历史不丢失**（修复预览清空行为）；切换自下一回合生效；进行中的回合继续用其启动时快照 | 单测（与 SL-06 联动） |
| MM-04 | 编辑档案把 base URL 换成另一主机 | key 不被自动发往新主机：要求显式重新输入或确认；沿用 loopback-http/https 校验规则 | 单测 + 行为文案检查 |
| MM-05 | 检查凭据去向 | key 仅存于专用凭据存储（独立文件或独立段），权限保守；导出/分享普通配置不包含；UI 回显仅末 4 位或掩码 | 单测 + 文件审查 |
| MM-06 | 旧版本/含未知字段/损坏的配置文件 | 未知字段按声明策略保留或忽略；版本升级有前向迁移钩子与旧 fixture 回归；损坏可诊断报错并备份，不静默清空用户配置 | fixture 回归（对齐持久化兼容合同） |
| MM-07 | 非法输入（超长名、控制字符、带凭据的 URL、重复档案名） | 显式校验错误，不落盘半合法档案 | 单测 |

## 依赖、风险与开放问题

- 依赖：session-lifecycle 的回合快照语义（MM-03/06 联测）；provider-streaming 的错误分类（MM-02 验证动作复用）。
- 风险：预览版用户仅有环境变量配置，新增文件配置需文档同步（AC-11 文档要求延续）；`~/.budingx` 与旧产品同目录但格式全新——**绝不读取或迁移旧产品数据**（AGENTS 禁止项）。
- OPEN：能力标记的最小集合（先只「支持工具调用」布尔，设计可扩）。
