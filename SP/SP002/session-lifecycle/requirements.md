# 会话生命周期与事件契约 · session-lifecycle

状态：APPROVED（v0.1 用户 2026-11-16 会话「批准」）｜迭代：SP002｜来源身份：USER_CONFIRMED（双中断模式为真实用法；路线图出口）+ MODEL_PROPOSED（状态机与 AC 切分）

## 来源与目标

- USER_CONFIRMED（2026-11-16 两轮答复）：用户真实用法包含两种中断——①立即打断改方向；②不停止、排队补充。两者都是一等场景。
- 路线图出口（USER_CONFIRMED）：「工具回合、取消和错误有证据；会话配置快照、事件/终态契约…明确」；质量要求「终态至多一次」「取消、超时、重试和副作用恢复有界」。
- 能力矩阵（核心行）：确认拒绝后会话继续；取消后子进程受控；SP002–007 保持宿主无关——**TUI 不得成为其他端前置**（I-11）。
- 机制参考（行为级）：[旧仓机制盘点](../attachments/old-repo-mechanism-inventory.md) §1/§2/§3/§5——tool_use 为唯一续跑信号、半截保留 + 合成 tool_result 补对、排队双注入边界、事件清单与终态裁决。实现独立编写。

## 范围与非目标

**范围**：会话与回合状态机；类型化事件契约（回合内增量与终态）；回合配置快照；执行中输入队列（优先级 + 注入边界）；取消传播链（UI 按键→会话→provider→工具句柄）；工具回合 round-trip（以注册的工具处理接口 + 测试桩工具证明契约，含审批挂起/拒绝路径的最小闭环）；单写者与终态裁决；Core 模块边界（O6 默认：同仓 Core 目录 + 独立构建，产出契约供 SP006 重评）。会话为内存态；**跨进程持久化与恢复属 SP005**，但事件与消息形状从本轮起按可回放设计。
**非目标**：真实工作区工具与权限规则系统（SP003）；转录持久化/schema/恢复（SP005）；上下文压缩策略（SP005）；多会话并行编排；跨端所有权（SP008）。

## 验收条件

| AC ID | 输入 / 动作 | 可观察结果 | 验证方式 |
| --- | --- | --- | --- |
| SL-01 | 检查状态机定义与运行 | 状态集合含 idle/requesting/streaming/tool_running/awaiting_approval/cancelling（名称以设计为准）；每回合**恰好一个终态**（completed|error|cancelled|length_capped…），重复/矛盾终态被拒绝并可断言 | 单测 + 状态机不变量测试 |
| SL-02 | 订阅一轮完整回合 | 类型化事件按契约顺序产出：回合开始→文本/思考增量→工具调用完成→工具结果→状态变化→终态；delta 先于对应 complete；形状不依赖任何 UI 类型 | 假 provider/假工具 fixture |
| SL-03 | provider 给出 1..n 个 tool_use（含 n=2） | 每个 tool_use 恰好一个 tool_result（含错误/合成情形）回填，按调用顺序入历史；非法参数/未知工具名→错误结果给模型且不崩；round-trip 可续跑至收敛 | fixture 驱动单测 |
| SL-04 | 流式/工具执行中触发**打断** | 有界时间内：模型请求取消、桩长任务收到取消句柄；部分 assistant 文本保留 + 孤儿 tool_use 补合成 error 结果（语义对齐盘点 §2，实现自有）；会话回 idle 可继续；被打断的原始输入回显可复用（auto-restore 行为，细节由设计定） | 单测 + 真实进程桩（可控取消延时上界断言） |
| SL-05 | 执行中输入 ≥2 条 → 排队指示可见 → 当前回合工具结果回填后、下一次模型调用前按序注入；slash/命令类只在回合边界处理 | 顺序保持、不丢失、不重复注入；回合间空闲时剩余项起新回合 | 单测（双注入边界各≥1 例） |
| SL-06 | 回合进行中切换模型/配置 | 本回合继续用启动快照；下一回合用新配置；快照内容（模型/参数/provider 标识）在事件或记录中可见 | 单测（与 MM-03 联测） |
| SL-07 | active 时再次发起回合/并发取消与完成竞态 | 第二请求被拒或入队（策略由设计定，行为唯一）；不出现交错写历史；取消与终态竞态裁决后仍「终态至多一次」 | 并发单测（注入时序） |
| SL-08 | 桩工具声明需审批 → 分别 approve / deny | deny：合成拒绝结果回填、**会话继续**、无挂起请求泄漏；approve：正常执行；审批请求带工具名/输入摘要/请求 id，应答按 id 匹配 | 单测（规则系统在 SP003，此处验接口与不泄漏） |
| SL-09 | 检查 Core 边界 | 会话/回合状态机位于 Core 目录，零 UI/终端 import；PS-07 的白名单 + lint 覆盖之；CLI 与未来宿主只经事件契约消费 | 脚本检查（并入 `npm test`） |
