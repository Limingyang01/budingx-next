# v0.4.0 · SP004 真实编码任务

状态为 **PREPARED**（尚未发布）。本版把编码任务闭环带进 TUI：命令执行、计划与待办、追问向导、受控 Git 提交，以及与之对应的四类会话区卡片。

- 新增 `Bash` / `PowerShell` 命令工具：命令、超时（毫秒）、说明与后台标志由模型提交；宿主决定工作目录与环境；未知参数直接拒绝。前台超过 15 秒自动转后台并回传任务 ID 与输出文件路径，输出写入 `~/.budingx/sessions/<sessionId>/tasks/`。
- 命令卡片显示原始命令、解释器、工作目录与状态，输出默认尾部若干行，`Ctrl+E` 展开；显示 `exit_code` 与耗时，后台任务给出任务 ID 与输出路径，取消后回到输入区。破坏性命令只提示警告，不阻断；仅可查看模式仍直接拒绝命令执行。
- 新增计划模式工具 `EnterPlanMode` / `ExitPlanMode`：调研期只读免审批，其他写或执行按次批准；计划正文存于 `~/.budingx/plans/<sessionId>/<planId>.md`，批准时可编辑正文并重算指纹，批准后恢复进入前的权限档位。计划执行前若目标文件被外部改动，会拒绝执行并把漂移项列回待审。
- 计划卡片显示阶段、目标、步骤状态与阻塞位置，`↑`/`↓` 移动焦点；待审批时 `1` 允许、`3` 或 `Esc` 拒绝、`e` 用输入框编辑正文后 `Enter` 提交。待办卡片由计划步骤派生，最近完成的项 60 秒后折叠，`Ctrl+E` 展开。
- 新增 `AskUserQuestion` 追问工具与卡片：一次 1–4 题、每题 2–4 个选项，支持单选、多选与自定义「其他」；`Tab` 切题、空格选择、`Enter` 确认或进入下一题、`Esc` 取消，回答以同一调用 ID 返回一个工具结果。
- 新增 Git 只读状态、改动归属、worktree 进出与受控提交：提交只发生在专用 `-budingx/` 分支的 worktree，授权绑定 HEAD、待提交文件、补丁摘要与期望树；删除 worktree 与分支需要宿主单次授权，存在未提交文件或未合并提交时还需显式丢弃批准。
- 新增编码任务目标状态机与完成证据校验（`TaskRedirect` 工具），但**未接入生产 runtime**：当前没有已验证的执行隔离后端，普通命令在启动前即被拒绝，接入会让会话空转。

- 追加可选本机 Langfuse 观测（agent-observability，**默认关闭**）：Core 追踪端口 + Session 回合/模型/工具埋点，`src/observability` 手写 OTLP 导出器（不引入 OTel SDK），本机 Langfuse 部署资产（`ops/langfuse`、`scripts/langfuse`），能力探针 `capability-probe.mjs` 与 trace 查询 `query-traces.mjs`，`buding-langfuse` skill。启用需 `BUDINGX_LANGFUSE_ENABLED=1` 与项目 Key；正文采集须再显式开启并经脱敏裁剪。追踪关闭或上报失败不改变 Agent 结果。

限制与未验证项：真实平台执行隔离后端未实现，普通命令在默认配置下不可用（fail-closed）；完成证据闸门在生产未启用；参考终端的像素级视觉对照、live Provider 端到端与发布包安装核验列为未验证，恢复条件见 [SP004 验收报告](../SP/SP004/test-report.md) §5。可选 Langfuse 观测的真实部署健康（OB-04）与 live 三场景（OB-24）亦为 UNVERIFIED，恢复条件见 [Langfuse STATUS](../SP/SP004/agent-observability/STATUS.md)。
