# v0.5.3 · TUI 工具修复与联网搜索

状态 **PUBLISHED**。npm `latest` 指向 **0.5.3**。

- `/effort` 打开思考强度选择菜单，支持方向键选择和回车确认。中文界面显示低、中、高。状态栏将上下文用量放在档位旁边，窗口已知时显示已用量、总量和一位小数的百分比。
- 会话绑定到启动时的实际工作区。`/sessions` 只列出当前工作区的会话，`/resume` 会在装载历史前拒绝其他工作区的会话。没有记录工作区的旧转录仍保存在磁盘，升级后不会自动归入任一工作区。
- `AskUserQuestion` 单题单选可直接确认，单题多选或多题会进入答案汇总。空格只切换选项，回车保留多选答案。汇总可返回改答，漏答会显示原因。「其他」使用追问自己的输入区，选项预览可用 `n` 填写备注。
- `Read`、`Write` 和 `Edit` 同时支持 `path` 和 `file_path`。读取空文件或越过末尾时给出提示，Notebook 可读单元格与文本输出。整文件写入保留传入的换行格式，编辑可匹配并保留弯引号。已有文件仍需先读，并检查读取后的文件改动。
- `Glob` 先按修改时间从早到晚排序再截断。`Grep` 默认返回命中的路径，想直接查看匹配内容时请显式使用 `output_mode: "content"`。搜索仍受工作区边界和读取规则限制。
- `EnterPlanMode` 给出会话专用计划草稿路径。`ExitPlanMode` 用原工具调用 ID 提交审批，返回用户最终批准的正文。权限意图只供审查，现有权限与计划漂移检查继续生效。
- `Bash` 和 `PowerShell` 在解释器或隔离后端不可用时提前报错，省去无法执行的审批。执行隔离可用时，显式后台等待按 `run_in_background: true` 处理。本制品尚未接入生产执行隔离后端，普通 Shell 命令仍不可用。
- 新增内置 `WebSearch`，适用于启用了工具调用的模型。设置 `BUDINGX_TAVILY_API_KEY` 时使用 Tavily，未设置时通过 Bing 公开搜索 RSS 查询。每次查询需审批，返回至多五条标题、网址和摘要，支持域名允许或排除列表。

图片仍仅读取元数据，PDF 页和 Notebook 图像输出尚未接入模型协议。Grep 使用 JavaScript 正则。Bing RSS 受服务可用性和网络限制，返回异常时工具会报告失败。真实 Tavily 查询和原生终端交互尚未验证。

可用 `npm install -g budingx@latest` 安装或升级，再用 `budingx --version` 核对版本。
