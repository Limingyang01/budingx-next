# v0.3.6 · SP002 与 SP003 终端交互修复

状态为 **PUBLISHED**。2026-11-18 已通过 GitHub Actions OIDC 发布，npm `latest` 指向 0.3.6。

- 全屏会话可用鼠标滚轮或翻页键查看长历史。上翻时保留草稿与新消息计数，Ctrl+End 回到最新消息。回合进度在输入框上方，排队预览在下方。
- 工具行在接收参数时已显示工具名。执行用时、紫色脉动与绿红结果沿用同一调用行。连续读取和搜索可折叠，Ctrl+O 打开完整转录并展开结果。
- Ctrl+R 搜索输入历史，在转录中按 / 搜索消息。文件补全支持目录内模糊匹配，交互 Diff 支持长行折行与常用语言着色。
- 交互权限为「允许编辑」和「全自动」。普通工作区写入可直接执行，敏感目标在编辑模式下逐次审批。仅可记忆的审批显示「本会话记住」。首次启动和旧只读偏好进入允许编辑，管道及 `--prompt` 仍默认只读。

详见 [产品说明书](../PRODUCT.md) 和 [差异清单](../SP/SP003/repl-alignment-gap-checklist.md)。Windows Terminal 的实际滚动、显示和 IME 仍待实机核对。运行 `npm install -g budingx@latest` 升级，再用 `budingx --version` 核对 0.3.6。
