# v0.6.0 · TUI 对齐与扩展（SP006）

状态 **PREPARED**（已合入 master，等待维护者触发 npm 发布）。本版补齐参考实现 TUI 的核心可用性与扩展面：四区骨架与帧级刷新、上下文键位、状态栏命令、命令注册表、项目指令、技能、MCP、受控 hooks、网页正文抓取与无头事件协议。

## 终端体验

- **四区布局**：header / transcript / input / footer 固定顺序；行数不足时优先压缩消息区并保持输入区与页脚可用。
- **帧差分与冻结缓存**：行级差异刷新；未变化、宽度未变的消息复用同一 React 元素，减少长会话重排。
- **上下文键位**：8 个上下文（global/chat/input/confirmation/transcript/help/select/footer）、组合键前缀、保留键保护；读取 `~/.budingx/keybindings.json`，损坏时回退默认并告警。
- **状态栏**：`config.json` 的 `statusLine` 可配置外部命令，经 stdin 接收会话/模型/成本/上下文 JSON，stdout 文本作为页脚附加行；超时、非 0、异常输出静默回退内置文案。
- **页脚归位**：模式、上下文占用、推理强度、快捷键与提示行统一在页脚区域，状态栏可多占一行。
- **命令卡片收口（0.6.0 修复）**：运行中/后台命令压成一行；完成、失败或取消后不再常驻输入区上方，结果保留在转录中，最近一次命令可按 `Ctrl+E` 按需展开。修复了单次工具调用重复占据多行的问题。
- **会话恢复可见性（0.6.0 修复）**：`/resume` 恢复出的历史对话重新回到消息区可见，并作为后续回合的上下文；当前会话身份同时切换到被恢复会话，续写内容写入该会话的转录，未决工具调用按「已中断」显示而不是继续转圈。
- **恢复排版修复（0.6.0 修复）**：流式回答改为按类型合并成单条消息，恢复历史时同一条消息内的连续文本再合并为一段；此前旧会话恢复后助手回答会被拆成十几条碎片、挤成极窄的竖条。旧会话文件无需迁移即可正确显示。
- **上下文续问建议（0.6.0 修复）**：回合结束后，空输入框的建议改由模型结合当前对话生成，不再使用固定话术；允许自然追问句。生成失败/超时/被取消/不合格时不显示。`BUDINGX_PROMPT_SUGGESTIONS=0` 可关闭。
- **退化终端命令输出（0.6.0 修复）**：行内界面下 `/help`、`/sessions` 等多行结果改为在页脚上方以正文块逐行显示（最多 40 行，超出提示截断），不再压成一行被折行裁切。
- **撤销提示语言（0.6.0 修复）**：没有可撤销的改动时，`/undo` 现在按界面语言提示（中文界面「没有可撤销的会话改动」），不再直接显示英文原因。

## 命令面

- **注册表三型**：`local`（内联文本）、`local-jsx`（只读/交互面板）、`prompt`（展开为模型提示）；既有 22 条命令行为不变。
- **新增命令**：
  - `/init`：生成项目指令（AGENTS.md）骨架提示；已有 AGENTS.md 时拒绝覆盖。
  - `/btw <问题>`：旁路提问，答案回显但不写入主会话历史、不调用工具。
  - `/worktree`：列出/创建/移除 Git worktree；删除必须经宿主确认并复用 SP004 授权边界。
  - `/tasks`：列出后台任务的状态、退出码与输出日志路径。
  - `/mcp`、`/skills`：只读列表；非交互模式退化为文本。
  - `/export`：导出会话为 JSONL 或文本，路径限定在用户数据根内，不覆盖既有文件。
- 命令帮助（中/英）同步新增七条。

## 项目指令与技能

- 项目指令按「用户级 → 工作区父目录（最多 3 层，遇 home/根即停）→ 工作区 AGENTS.md → CLAUDE.md → 子目录（显式开启）」加载，单文件 64 KiB、总量 128 KiB 截断并告警，作为系统上下文注入且下一回合生效。
- 技能扫描 `~/.budingx/skills` 与 `<workspace>/.budingx/skills`，项目级同名覆盖用户级；frontmatter 缺失/正文为空标记为不可用，并以 `/<skill>` 提示命令暴露。

## MCP、hooks 与网页抓取

- **MCP stdio**：initialize → notifications/initialized → tools/list；工具名 `mcp__<server>__<tool>`；连接 10s、调用 30s；全部调用走既有审批；密钥只接受 `${ENV_NAME}` 引用，明文配置被忽略；单服务器失败降级不影响其它服务器。
- **受控 hooks**：SessionStart / UserPromptSubmit / PreToolUse / PostToolUse / PostToolUseFailure / Stop / StopFailure / Notification 八个事件；支持 command 与 prompt 处理器；退出码 2、`decision=block`、`permissionDecision`、`updatedInput`、`additionalContext` 均按契约生效；超时/非 0/损坏配置降级，不使回合崩溃。
- **WebFetch 工具**：抓取前审批；默认拒绝内网/回环/链路本地地址；HTML 提取正文；512 KiB 截断并显式标注；重定向最多 3 次且每次重查内网；超时 15s。

## 无头 CLI

- `--output-format text|json|stream-json`、`--input-format`、`--input-file`、`--session`、`--verbose`。
- stream-json 事件：system init/status、user、assistant（增量与整段）、tool_call、tool_result、result；result 恒为最后一行。
- 参数错误退出码 2，回合失败 1；无 `--session` 时不写会话数据；stdout 只承载协议，提示走 stderr。

## 已知限制

- hooks 仅 command/prompt 两类处理器与 8 个事件；http/agent 处理器与其余事件未实现。
- MCP 仅 stdio 与 initialize/tools/list/tools/call；OAuth 远程服务器、resources/prompts、动态工具刷新未实现。
- 键位仅 8 个上下文；vim 双模式、鼠标选区、备用屏与单元格级差分未实现。
- `/tasks` 展示宿主登记的后台任务；模型回合中的工具执行尚未自动登记为任务。
- `statusLine` 配置在启动时读取，修改后需重启 TUI。
- 本版尚未发布 npm；版本台账为 `prepared`，发布由维护者在合入 master 后触发发布工作流。
