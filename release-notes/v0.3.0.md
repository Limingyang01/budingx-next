# v0.3.0 · SP003 工作区与安全修改

状态：**PUBLISHED**。2026-11-18 已发布到 npm，发布时 tag 为 latest。

## 本版变更

- 工具型模型可在当前工作区调用 `Read`、`Glob`、`Grep`、`Write` 和 `Edit`。现有文件需先读取，外部改动会使旧的修改计划失效。
- 可用 `@路径#L10-20` 引用文件行范围。补全支持目录续补、文件名模糊查找和带空格路径的自动引号。排队的提示词发送前读取最新的允许内容。
- 默认仅可查看。用 Shift+Tab 或 `/permission` 切换三种模式，需要审批时可先浏览写入 diff，并选允许一次、记住目标或拒绝。权限规则和拒绝记录分别通过 `/rules` 和 `/denials` 查看。
- `/diff` 可看本会话的当前、逐回合及 Git 工作区差异。`/undo` 撤销最近一组改动，`/undo <路径>` 撤销该文件最近一次改动。若磁盘内容已被外部修改，自动撤销会停止。

## 升级与适用范围

发布后运行 `npm install -g budingx@0.3.0`，再用 `budingx --version` 确认输出 `0.3.0`。需要 Node.js ≥22.18。npm 包名、`budingx` 命令和模型配置格式兼容 0.2.0。默认权限保守，原有模型档案继续从 `~/.budingx` 读取，权限规则使用新增的 `permissions.json`。

本版仍是 TUI 单端交付。命令执行、跨会话撤销和图片内容传入属于后续迭代。工作区与搜索均有范围和大小上限，超限时提示；文件撤销只针对当前会话。
