# budingx 0.1.0

Independent MIT terminal chat preview built with Node.js and TypeScript. This is a bootstrap release, not completion of an SP or a full replacement Agent.

- OpenAI-compatible Chat Completions streaming, explicit model/base URL, BUDINGX_API_KEY environment configuration.
- In-memory multi-turn chat, /help /config /model /endpoint /clear /exit, cancellation and bounded request timeout.
- No file/command tools, saved history, credentials discovery, Desktop/VSIX, Computer Use, teams, remote access, IM or scheduler yet.
- Node >=22.18 required. Initial packaging and automated process checks are performed on Windows; other platforms are not yet installation-certified.
- Public Provider live testing requires explicit test credentials; HTTP fixtures are not proof of a particular external model's compatibility.

See the repository release report for the exact checks and publication receipt. Product version source: src/tui/package.json; iteration mapping: release-ledger.json.
