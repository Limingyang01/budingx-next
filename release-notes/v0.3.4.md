# v0.3.4 · SP003 权限模式与会话体验

状态为 **PREPARED**。本候选包含 0.3.3 原定的会话修复，公开版本仍为 0.3.2。

## 权限模式

- 交互终端用 Shift+Tab 或 `/permission` 切换后，保存选择到 `~/.budingx/permission-mode.json`，再启动时恢复。该偏好在同一用户的工作区之间共享。
- 状态栏用青色、黄色、红色区分只读、工作区内修改和完全权限。完全权限额外显示「全自动 · 可获准的写入免审批」。拒绝规则、凭据保护和工作区边界继续生效。
- 首次启动、偏好无效或权限规则损坏时默认只读。管道和 `--prompt` 从只读启动。

## 会话体验

- 保留已提交提问，显示工作阶段、耗时与本地结束时刻。
- 模型请求携带 budingx 产品身份和配置的模型 ID。终端显示思考阶段和回答正文。
- 回答完成后在空输入框显示续问建议。按 Tab 填入，可编辑后按 Enter 发送。

使用说明见 [产品说明书](../PRODUCT.md)，验证边界见 [SP003 验证报告](../SP/SP003/test-report.md)。发布工作流参数为 master、0.3.4、latest。发布后可运行 `npm install -g budingx@latest` 升级。
