# budingx 0.1.1 · bootstrap maintenance

This patch consolidates release-process fixes and validates the first real GitHub Actions / npm Trusted Publishing release. The product remains an MIT chat-only TUI preview; no new coding-agent tools or SP completion is claimed.

## Changes

- Publish only the TUI package from src/tui through the manual master workflow, using hosted runners and npm OIDC without a personal npm token secret.
- Verify Windows/Linux tests and real tarball installation before release; upload that same tested tarball and check registry integrity, dist-tag and installed CLI behavior.
- Wait for an accepted upload to become publicly visible during npm processing; retry only bounded metadata reads and never repeat the upload.
- Keep the unused publish:otp experiment removed; interactive account bootstrap and CI/OIDC remain separate paths.
- Allow the already-published bootstrap phase to prepare a patch without inventing an SP number, preserving release history and unknown ledger fields.
- Refresh the package README to reflect verified Windows/Linux checks and the maintenance release scope.

## Validation and limits

Local regression, packaging checks and the GitHub run results are recorded in the bootstrap STATUS and release ledger. The release workflow must succeed before this release is marked published. A fixture HTTP model is not proof of a particular external provider's compatibility; live external-model testing remains unverified.

Node.js >=22.18 is required; Bun is not used. Session data remains in memory. Desktop/VSIX/mobile, shared history, file/terminal tools, teams, Computer Use, remote access, IM and scheduling remain in the product roadmap.
