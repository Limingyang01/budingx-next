# v0.5.4 · 命令执行、联网搜索审批与长会话显示修复

状态 **PREPARED**（已准备，尚未上传 npm）。本版修复 0.5.3 的一批可用性与显示问题，并对齐参考实现的命令执行模型。

## 命令执行（Bash/PowerShell 可用）

0.5.3 及之前，普通终端命令因「无已验证执行隔离后端」在启动前一律被拒绝（`BUDINGX_EXEC_005`），Bash 实际不可用。本版对齐参考实现（`buding-worker-space`）的模型：**权限审批是安全控制，沙箱是可选加固层**。

- 未配置隔离后端时采用「宿主信任执行」：只读白名单命令免审批；其余命令按权限档位审批——仅可查看拒绝、工作区内修改逐次确认（可「本会话记住」）、完全权限自动执行。
- 若宿主配置了已验收的隔离后端，命令在该隔离中执行，模型不能选取/关闭/降级隔离（`dangerouslyDisableSandbox` 等字段仍一律拒绝）。
- 保留既有的交互式/阻塞命令拦截、超时与硬上限、破坏性命令警告、Git 写操作受控入口指引。
- **安全提示**：默认无 OS 级隔离，完全权限档位下命令直接执行。若不希望命令外发或改动系统，请使用「工作区内修改」或「仅可查看」档位。OS 级隔离后端接口已就绪，内置已验收后端待后续迭代。

## 联网搜索审批

- **完全权限下不再为 `WebSearch` 弹审批**：0.5.3 将其设为无条件强制审批，绕过了三档判定。现改为独立的「出网」能力，按档位判定（完全权限自动；其余逐次确认）。
- **新增「本会话记住」**：出网确认可选 `2 本会话记住`，同工具后续搜索不再反复打断。
- **修正 `approved` 口径**：此前仅审批框放行时置真，档位自动放行时仍为假，导致出网工具自保护检查在完全权限下误拒。现在调用被授权执行即置真；工具保留出网前自检兜底。

## 审批卡与显示

- **审批卡编号与按键一致**：不可「本会话记住」时由 `1/3` 改为 `1 允许一次 · 2 拒绝（或 Esc）`，按 2 即进入拒绝；可记住时仍是 `1 / 2 本会话记住 / 3 拒绝`。
- **追问卡回答后收起**：答案随工具结果交付并进入转录后，实时追问卡即消失，不再长期占位。
- **过程性提示不再堆叠/常驻**：重试 `attempt 1/5、2/5` 只保留最新一条，且回合结束即收起；@ 引用反馈在新回合开始时收起。错误/告警类提示保留。
- **时长按 小时/分钟/秒 显示**：完成 meta 与运行中状态栏由「469 秒」改为「7 分钟 49 秒」（省略为零的高位）。
- **状态措辞**：请求/流式阶段统一显示「正在思考…」，不再出现「流式输出中」「请求中」等实现措辞。
- **模式轮播恢复三档**：Shift+Tab 现为「仅可查看 → 工作区内修改 → 完全权限 → 仅可查看」；此前从完全权限会跳回工作区内修改，无法再回到仅可查看。仅可查看徽标更名为「仅可查看」。
- **Git 命令不再被白名单硬拦**：此前任何非只读白名单内的 Git 命令（如 `git add`、`git commit`、`git push`）在通用命令入口一律被拒，即使处于完全权限。现在与其它命令一致，按权限档位审批（仅可查看拒绝、工作区内修改逐次确认、完全权限自动）。
- **底部信息压缩为一行**：模式、上下文用量、推理强度、快捷键合并到同一行，去掉单独的「可获准的写入免审批」行，减少常驻占据行数。
- **上下文占用改为百分比（真实用量）**：状态栏显示「饼图字形 + 百分比」（如 `◑ 32.8%`），只用模型真实上报的输入 token，不再用本地估算；窗口缺省 200k，可用 `BUDINGX_CONTEXT_WINDOW` 覆盖。
- **`/rules` 交互管理面板**：参照 `/models`，↑↓ 选择、`a` 新增、`d` 删除、Esc 关闭；管道模式仍列出规则。
- **移除 `/config` 与 `/model`**：不再出现在 `/` 命令列表与 `/help`；模型切换统一走 `/models`。
- **修复长会话崩溃**：消除 Ink `useBoxMetrics` 与虚拟列表间距互相驱动的同步更新链，长会话不再抛 React `Maximum update depth exceeded`。
- **Langfuse 仅开发环境**：默认不启用、启动不再向用户打印内部诊断。
