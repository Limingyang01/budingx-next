## 变更

- `/branch`（`/fork`）、`/rename` 和 `/resume` 正文搜索补齐会话管理。`/export --format markdown` 可导出选定会话及其可归属的文件修改。
- Ctrl+S 暂存和取回草稿。长粘贴可用 Ctrl+G 查看，确认后发送。Ctrl+O 进入转录，Ctrl+E 全量展开，Enter 可切换选中的思考段。
- 技能支持独立的手动/模型开关、安全资源引用和回合级 `allowed-tools`。项目指令支持受信导入与相应目录的局部规则。
- `/tasks` 支持查看和停止本会话后台 Shell、子代理。`/worktree` 支持进入、退出、重启恢复及显式确认合并。
- MCP 支持 stdio、Streamable HTTP、SSE 和 WebSocket，资源列出和读取、启停与重连，以及简单确认请求。
- WebFetch 长页返回最多 32768 个 UTF-16 码元的可用文本。真正执行失败继续受熔断保护，父 Agent 可读取子代理失败原因和部分结果。

## 兼容性

- Node.js >=22.18，bin 和用户数据根仍为 `budingx` 与 `~/.budingx`。0.9.1 会话、模型档案和 JSONL/文本导出继续可用。
- 同一会话由一个活动进程写入。`/resume` 遇到其他写者会提示，派生后的会话独立取得写锁。
- Windows 统一按物理路径识别 8.3 短路径和长路径，确保工作区、规则读取及用户数据保护使用一致的路径。旧会话仍可用原启动路径恢复。
- MCP 的既有 stdio 配置形状继续可用。子进程继承基本系统变量，其他变量按服务器在 `env` 中显式引用，例如 `"${ENV_NAME}"`。WebSocket 使用 `mcp` 子协议。

## 升级

运行 `npm install -g budingx@0.9.2`。旧会话可用 `/resume` 恢复。若需要回到上一版，安装 `budingx@0.9.1`，提前保留 0.9.2 新增的会话元数据和工作树绑定副本。

## 已知限制

- 旧会话和缺少归属记录的 Shell/Git 改动无法推导出 Markdown 改动证据。局部规则按工具声明的路径生效，Shell 的命令文本不会改变声明的 cwd。
- MCP 交互仅支持空表单确认。OAuth、sampling 和复杂表单不在本版范围。第三方 MCP 服务兼容性待授权环境补测。
- Worktree 合并保护源与目标的工作区和暂存区。存在 Git 忽略文件时，预检需要 Git 2.38+。后台任务由启动进程管理。
- 原生终端 IME、鼠标观感与 Provider 实际费用为 UNVERIFIED。
