# v0.3.1 · SP003 模型管理修复

状态：**PREPARED**，等待维护者手动触发发布。npm `latest` 当前为 0.3.0。

## 本版变更

- `/models` 在交互终端打开模型管理。用 `N` 新建、`E` 编辑、`D` 删除、`T` 测试，选中档案后 Enter 切换。表单带入原值，删除有确认和活动／启动默认替代选项。
- 内置 DeepSeek、Qwen／阿里云百炼、Kimi／月之暗面、GLM／智谱、火山方舟／豆包、硅基流动、OpenAI 与 OpenRouter 模板。选模板、在隐藏字段粘贴 API Key 并按 Enter，即可请求模型列表。Custom 可手填兼容端点和模型 ID，模型发现失败时仍可手填。
- 密钥按档案与端点主机绑定，输入时不回显。编辑改主机需使用该主机的密钥。连接测试提供鉴权反馈，支持取消。
- `/provider` 已移除。交互维护改用 `/models`；管道中的 `/models` 仍列出档案，`/model <名称或ID>` 仍可切换。产品使用说明已按 Bootstrap、SP002、SP003 重整并补齐命令示例。

## 从 0.3.0 升级

发布后运行 `npm install -g budingx@latest`，再用 `budingx --version` 核对 `0.3.1`。需要 Node.js ≥22.18。既有档案和凭据可继续使用；若脚本调用了已移除的 `/provider`，请改用交互面板维护档案，自动化调用使用 `/model`、启动参数或环境变量。用法见 [产品说明书](../PRODUCT.md#模型管理)。
